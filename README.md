# windows-cache-cleaner
基于 PowerShell 的 Windows C 盘缓存清理工具，支持分级清理、空间分析、清理预演、分阶段提权与详细日志，默认保留个人文件和系统恢复数据。  A PowerShell-based Windows C: drive cache cleaner with tiered cleanup, space analysis, dry runs, staged elevation, and detailed logs. Preserves personal files and system recovery data by default.
